# 外壁カラーシミュレーター（高藤邸 プランNo.2）

`facade-simulator/index.html` をブラウザで開くだけで動く、外観パースの外壁カラーシミュレーターです（ビルド不要・three.js は CDN から読み込み）。

- 平面図・立面図（間口 4,345 × 奥行 10,010 mm、木造3階建、インナーガレージ、3階インナーバルコニー）から作った 3D パース
- 外壁を **3階／2階／1階／インナーガレージ** の4部位で個別に塗り分け
- 窓枠（サッシ）・軒天・屋根／破風・玄関ドアの色を切り替え（カスタム色も可）
- **2画面比較**（プランA／B、視点連動、A→Bコピー）
- 屋根形状：片流れ（ケイミュー外観パース準拠）／寄棟（立面図準拠）
- 3Dの壁をクリックすると、その部位がパネルで選択される
- 「画像にする」で凡例付きの比較画像（PNG）を作成
- ケイミューの公開情報から品番・色名を確認できた外壁材 28 点を収録（レジェール ピアレスストーン、光セラ18 シュトラール18／マレストーン18／シンプルストライプ18／メッシュライン／セラトピア、光セラ16 シックボーダー、SOLIDO typeM_LAP）。表示色は色名からの近似色。出典はアプリの「使い方」内に記載
- 一覧にない品番は「外壁材を登録」から追加可能（ブラウザに保存）
- 「使い方」ボタンで操作ガイドを表示。スマホではパースを上部に固定したままパネルをスクロールできる

※ 画面上の色は実物と異なります。最終決定は実物サンプルでご確認ください。
