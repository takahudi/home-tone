# 外壁カラーシミュレーター（高藤邸 プランNo.2）

外観パースの外壁カラーシミュレーターです（ビルド不要・three.js は CDN から読み込み）。外壁の柄画像を読み込むため、`facade-simulator/` を Web サーバー経由（GitHub Pages、または `python3 -m http.server` など）で開いてください。ファイルを直接開くと柄が出ず、色のみの表示になります。

- 平面図・立面図（間口 4,345 × 奥行 10,010 mm、木造3階建、インナーガレージ、3階インナーバルコニー）から作った 3D パース
- 外壁を **3階／2階／1階／インナーガレージ** の4部位で個別に塗り分け
- 窓枠（サッシ）・軒天・屋根／破風・玄関ドアの色を切り替え（カスタム色も可）
- **2画面比較**（プランA／B、視点連動、A→Bコピー）
- 屋根形状：片流れ（ケイミュー外観パース準拠）／寄棟（立面図準拠）
- 3Dの壁をクリックすると、その部位がパネルで選択される
- 「画像にする」で凡例付きの比較画像（PNG）を作成
- ケイミュー「外壁材商品ラインナップ」（P.126〜137）の **254色** を収録（レジェール、FLAT DESIGN PANEL、ネオロック・光セラ18 セラトピア、ネオロック・光セラ18）。品番・色名・定価・張り方つき。壁の柄はカタログの色見本画像を実寸（見本の高さ＝455mm）で貼り付け（`facade-simulator/kmew/`）
- 品番・色名で検索、シリーズ・色の系統で絞り込み。縦張り対応の柄は縦張り表示に切り替え可能
- 一覧にない品番は「外壁材を登録」から追加可能（ブラウザに保存）
- 「使い方」ボタンで操作ガイドを表示。スマホではパースを上部に固定したままパネルをスクロールできる

※ 画面上の色は実物と異なります。最終決定は実物サンプルでご確認ください。
