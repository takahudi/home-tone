# 外壁カラーシミュレーター（プランNo.5）

外観パースの外壁カラーシミュレーターです（ビルド不要・three.js は CDN から読み込み）。

**公開ページ：** https://takahudi.github.io/home-tone/ （`main` に push すると GitHub Actions で自動更新。内観は https://takahudi.github.io/home-tone/#interior ）

外壁の柄画像を読み込むため、`facade-simulator/` を Web サーバー経由（GitHub Pages、または `python3 -m http.server` など）で開いてください。ファイルを直接開くと柄が出ず、色のみの表示になります（内観も開けません）。

**ローカルで開く（uv + Python 3.12）：** 初回だけプロジェクト直下で `uv sync` を実行して仮想環境（`.venv`）を作り、以降は `uv run serve.py` でサーバーが起動してブラウザで `http://localhost:8000/` が開きます（`--port 9000`、`--no-browser` も指定可、Ctrl+C で停止）。Windows なら `facade-simulator/start.cmd` のダブルクリックでも同じように開けます（黒いウィンドウを閉じると停止）。

- 平面図・立面図（プランNo.5／2026.11.10版。間口 4,400 × 奥行 10,010 mm、木造3階建、インナーガレージ、3階インナーバルコニー）から作った 3D パース
- 外壁を **3階／3階インナーバルコニー内／2階／1階／インナーガレージ** の5部位で個別に塗り分け
- 窓枠（サッシ）・軒天・屋根・破風（屋根と別に選択、または屋根と同色）・玄関ドアの色を切り替え（カスタム色も可）
- 屋根はケイミュー カラーベスト コロニアル遮熱グラッサの全9色（クールブラック CC862K ほか）から選択。柄はケイミュー商品ページの色見本（`facade-simulator/kmew/roof/`）
- 軒天の木目調はニチハ 軒天14（14mm厚品）無孔板 YL251 ライト／YL252 ミディアム／YL253 ダークから選択（`facade-simulator/nichiha/`）
- 門柱（塗り壁＋縦スリット2本、門灯・ガラス表札・インターホン・ポスト口付き）と角柱3本。表示切り替え、門柱と角柱で別々に色を選択
- 玄関ドアは YKK AP 断熱玄関ドア ヴェナートD30 のナチュラル18デザイン・シック10デザイン（通風タイプは除く）から、デザイン×色（各デザインのカラーバリエーション、計200通り）で選択（カタログのカラーバリエーション写真を使用、`facade-simulator/ykk/`）
- **プランA／B**：1画面でA・Bのどちらかを選んで表示・編集するか、2画面で並べて比較（視点連動、A↔Bコピー）
- 屋根形状：片流れ（ケイミュー外観パース準拠）／寄棟（立面図準拠）
- 3Dの壁をクリックすると、その部位がパネルで選択される
- 「画像にする」で凡例付きの比較画像（PNG）を作成
- 光：暖色（従来の設定）／白（日差しを白に）／晴天（白い日差し＋青空の光を強めに、少し明るく）から選べる。A・B 共通で、ブラウザに保存
- ケイミュー「外壁材商品ラインナップ」（P.126〜137）の **254色** を収録（レジェール、FLAT DESIGN PANEL、ネオロック・光セラ18 セラトピア、ネオロック・光セラ18）。品番・色名・定価・張り方つき。壁の柄はカタログの色見本画像を実寸（見本の高さ＝455mm）で貼り付け（`facade-simulator/kmew/`）。レジェール30色はケイミュー商品詳細ページの1枚分の高解像度画像（約1700×333px、働き幅455mm×約2.3m）を使用（`facade-simulator/kmew/legerair/`）。FLAT DESIGN PANEL 22色は総合カタログ P.86〜92 のパネル1枚の写真から働き幅455mm の帯を切り出して実寸で使用（グラフィルは3種類のランダム柄を横に並べたもの、`facade-simulator/kmew/fdp/`）
- 品番・色名で検索、シリーズ・色の系統で絞り込み。縦張り対応の柄は縦張り表示に切り替え可能
- 一覧にない品番は「外壁材を登録」から追加可能（ブラウザに保存）
- 「保存・読込」で、外観（A・B案、登録した外壁材）と内観（A・B案、全部屋）の今の状態を JSON ファイルに書き出し・読み込み（別のブラウザや端末に移せる）
- 「使い方」ボタンで操作ガイドを表示。スマホではパースを上部に固定したままパネルをスクロールできる

※ 画面上の色は実物と異なります。最終決定は実物サンプルでご確認ください。

## 内観モード（`facade-simulator/interior.js`）

画面上の「外観／内観」で切り替え（URL 末尾 `#interior` で直接開ける）。プランNo.5 の平面図から LDK（16.26帖）・1階洋室（7.25帖）・3階洋室A／B／C（7.7／4.9／6帖）を、窓・ドア・収納・キッチン付きで再現。

- 壁紙（18種）、アクセントクロス（3Dで壁をクリックして1面指定）、天井、床、室内ドア・収納扉の色
- 室内ドア・収納扉は Panasonic ieria（イエリア）のスタンダード8色・セレクト11色から選択（カタログの色見本、`facade-simulator/interior/door/`）。ドア枠は白／黒、ハンドルはシルバー／黒から選択
- 床は DAIKEN トリニティ YN7701（12色、DAIKEN 公式サイトの柄見本の写真）と MYフロア（17色、色見本。303mm幅として表示）を実物の柄で、1/2・1/4ずらし張りで表示（`facade-simulator/interior/floor/`）。色だけの簡易表示も選べる
- キッチンはトクラス コラージア スリムフラットW の形（東の壁に付けた壁付けフラット。コンロ側の端に天井までのキッチンパネル、サイドフード、オイルガード。作業側はグリル付きコンロ下・食洗機・引き出し）。レンジフード（サイドフード SHVR）はシルバー／ブラック／ホワイト、シンク（人造大理石の H2シンク）はホワイト／シックベージュ／グレージュ／グレー（色はトクラスのカラーシミュレーションの CG に合わせた）、取っ手（ロングバー取手）はシルバー／ブラックから選択
- キッチン・カップボードは、扉・本体の色を扉シリーズ（リッチマテリアル以外の Z／Y／N／S／D／Q／J／B シリーズ、23色）から、天板を人造大理石「テノール」カウンター（4色）から（カップボードはメラミンポストフォームのホワイト・ダークグレーも）、それぞれ別々に選択。カタログの色見本を貼って表示（`facade-simulator/interior/kitchen/`）。扉と天板（テノール）の色は、トクラスのカラーシミュレーション（スリムフラット-W）の CG の見え方に合うよう、色ごとに補正して表示（色見本の一覧はカタログの画像のまま）。3Dでクリック、または「壁紙・床」タブで選ぶ
- カップボードは、ハイカウンタータイプ用キャビネット（H1025・D450。4段引出し＋家電送風機オープンタイプ）とウォールキャビネット（H600・D450）の組み合わせ。間から北の小窓が見える
- 冷蔵庫は Panasonic NR-E45RY3（450L、幅60×奥行64.8×高さ185cm）。色はシルバー／マットライトベージュから選択
- 家具（ソファ、ダイニング、テレビボード、ベッド、デスク、収納、ラグ、観葉植物など）の追加・移動・回転・色変更
- 照明（ダウンライト・シーリング・ペンダント）の配置と照明色（電球色／温白色／昼白色）。昼／夜切り替えで明かりを確認
- コンセント・スイッチ・TV端子・LAN・エアコンを壁に配置（ドラッグで壁から壁へ移動、高さ指定）。部屋ごとの個数を表示
- 視点：俯瞰／真上（図面）／入口から／奥から。設定はブラウザに保存
- 外観と同じく **プランA／B** を持てる。「1画面 A／1画面 B」で一方を表示・編集、「2画面で比較」で並べて比較（視点連動）。「A の内容を B にコピー」で全部屋をまるごとコピー。「保存・読込」のファイルにも A・B 両方が入る（B のない古いファイルを読み込むと、B は A のコピーから始まる）
